KEY FEATURES IMPLEMENTED
========================
- 126-channel scanning (0-125) with frequency calculation: 2400 + channel
- Activity percentage: (RPD_positive / valid_samples) * 100
- Unicode terminal bars with Clear/Moderate/Busy/Heavy Load status
- Wi-Fi reference overlays at channels 12/37/62 (2412/2437/2462 MHz)
- ARMED/DISARMED mitigation - passive only, no interference
- CSV/JSON/PNG exports with all channels including clear ones
- Thread-safe SpectrumData with rolling history & waterfall
- Deterministic simulation with seed for reproducible tests

HARDWARE WIRING (Required for Hardware Mode)
=============================================
| nRF24L01+ | Raspberry Pi          |
|-----------|-----------------------|
| VCC       | 3.3V (Pin 1)          |
| GND       | GND (Pin 6)           |
| CE        | GPIO25 (Pin 22)       |
| CSN       | GPIO8/CE0 (Pin 24)    |
| SCK       | GPIO11 (Pin 23)       |
| MOSI      | GPIO10 (Pin 19)       |
| MISO      | GPIO9 (Pin 21)        |
| IRQ       | Not connected         |

NOTE: Use 3.3V power only. Enable SPI via raspi-config.

CONFIGURATION
=============
All settings in config.py via AppConfig dataclass:
- ChannelConfig: start_channel, end_channel (default 0-125)
- ScanConfig: measurement_window, sampling_interval, min_valid_samples
- ThresholdConfig: clear_max, moderate_max, busy_max, heavy_min
- MitigationConfig: persistent_threshold, persistence_duration, armed
- StorageConfig: rolling_history_size, waterfall_history_size
- GUIConfig: refresh_interval_ms, spectrum_max_channels

LOGGING
=======
Countermeasures events logged to logs/countermeasures.jsonl (JSON Lines)
Includes: timestamp, event_id, channel, frequency, activity%, samples, threshold, classification, recommendations

EXPORTS
=======
- CSV: All channels with raw counts and calculated percentages
- JSON: Structured with config, scan_count, observations array
- PNG: Current spectrum or waterfall via file dialog

LIMITATIONS (Documented)
========================
- nRF24L01+ is narrowband transceiver, not calibrated spectrum analyzer
- RPD is binary (energy detected/not detected), no dBm calibration
- Cannot identify Wi-Fi/Bluetooth/Zigbee protocols
- Scans channels sequentially (single frequency at a time)
- Results depend on antenna type and placement
